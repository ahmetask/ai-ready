# myagent

## Commands
- Setup: `make setup` (pnpm install, scaffold the worker's gitignored `.dev.vars`, local D1 schema)
- Dev: `make dev` (worker :8787 + hub :5173)
- Typecheck: `pnpm typecheck` · Build: `pnpm build`
- No test suite, linter or CI exists; typecheck is the only automated check.

## Guardrails
- `make deploy`, `make bootstrap`, `pnpm run deploy` and any `wrangler ... --remote` / `secret put` hit the live Cloudflare account. Don't run them unless asked.
- `make dev` / `make stop` / `make kill` run `pkill -9 -f wrangler` and `workerd` machine-wide, and kill whatever holds ports 8787/5173.
- `agents/language/src/generatedContent.ts` says it's generated by a `build-questions.mjs` script, but that script isn't in the repo. Ask before editing or regenerating it.
- Never commit `.dev.vars`, `.env.deploy` or secret values. The IDs in `wrangler.jsonc` are not secrets and are committed.

## Gotchas
- Use `pnpm run deploy`, never `pnpm deploy` (pnpm builtin → `ERR_PNPM_NOTHING_TO_DEPLOY`).
- `VITE_API_BASE` is baked into the hub at build time. Without it the hub calls `/api` on Pages and gets HTML back.
- New D1 tables need their `schema.sql` applied locally (`make db`) and remotely (see DEPLOY.md).
- Adding an agent: follow [DEPLOY.md](./DEPLOY.md#adding-a-new-agent-later), which covers the worker's `AGENTS` and the hub's panel registry.
